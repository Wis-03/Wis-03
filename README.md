## Featured projects

### [EBank — Agentic AI Banking Platform](https://github.com/Wis-03/ebank)

A Spring Cloud microservices banking application with a Spring AI assistant. The assistant uses bounded ReAct tool calls through MCP to query business services and retrieves supporting content from a multimodal RAG pipeline backed by PostgreSQL and pgvector. The repository documents the architecture and Docker Compose setup.

**Stack:** Java 21 · Spring Boot · Spring Cloud · Spring AI · MCP · PostgreSQL · pgvector · Angular · Docker

### [NYC Taxi Trip Duration — PySpark](https://github.com/Wis-03/nyc-taxi-trip-duration-pyspark)

A distributed regression workflow for the Kaggle NYC Taxi Trip Duration dataset. The notebook covers data cleaning, temporal and geospatial feature engineering, and cross-validated comparisons of three regression models. The repository reports a best tree-based validation result of **≈341 seconds RMSE, ≈214 seconds MAE, and R² = 0.724**; see its README and notebook for evaluation details.

**Stack:** Python · PySpark · Spark MLlib · pandas · NumPy · scikit-learn
